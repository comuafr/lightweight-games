# BACKLOG — vetted game concepts

Each entry is one repo. All are public-domain / generic mechanics — NO
trademarked names or assets. Pick a generic title; confirm availability before
publishing. Prefer simple, "complete in one sitting" games that fit the size
budget and need no art beyond vector shapes.

Status: [ ] todo  [~] in progress  [x] shipped

## Tier 1 — simplest, prove the pipeline first
- [~] `snake` — "Snake": grow by eating, die on wall/self. (reference game)
- [ ] `light-out` — "Light Flip": toggle lights + neighbors until all off.
- [ ] `memory-match` — "Memory Match": flip pairs of cards.
- [ ] `slider-2048` — "2048-style" merge puzzle. Generic title e.g. "Merge 2048".
- [ ] `mine-sweeper` — "Mine Sweeper": reveal cells, flag mines.

## Tier 2 — needs more logic / collision work
- [ ] `brick-breaker` — "Brick Breaker": paddle + ball + brick grid.
- [ ] `falling-blocks` — falling-tetromino puzzle. Generic title, NOT "Tetris".
- [ ] `box-pusher` — "Box Pusher": Sokoban-style push crates onto targets.
- [ ] `block-puzzle` — "Block Puzzle": place pieces, clear lines.
- [ ] `peg-solitaire` — "Peg Solitaire": jump pegs, leave one.

## Tier 3 — bigger, do after the line is proven
- [ ] `solitaire` — "Klondike Solitaire" (card game; public domain rules).
- [ ] `mahjong-solitaire` — "Mahjong Solitaire": match free tiles. (watch art size)
- [ ] `maze-muncher` — dot-eating maze game. Original maze + characters ONLY.

## Naming discipline
Never use: Tetris, Pac-Man, Space Invaders, Donkey Kong, Frogger, Galaga,
Bomberman, Sonic, Mario, Centipede, Q*bert, Dig Dug, Asteroids, Breakout, 2048
(the app — the number is fine), Candy Crush, Bejeweled. When unsure, choose the
descriptive generic name and flag it in REVIEW.md.
